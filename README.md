# 🥬 VegCare AI (ระบบวิเคราะห์สุขภาพและโรคผักสวนครัว & ทุเรียนอัจฉริยะ)

แอปพลิเคชันปัญญาประดิษฐ์ (AI) สำหรับเกษตรกร ผู้ปลูกผักสวนครัว และชาวสวนทุเรียน ที่ช่วยตรวจสุขภาพพืช วินิจฉัยโรคพืช วิเคราะห์อาการผิดปกติ พร้อมให้แนวทางการรักษาและฟื้นฟูอย่างละเอียด ทั้งแบบอินทรีย์ ปลอดสารพิษ และการใช้สารควบคุมโรคอย่างปลอดภัย

---

## ✨ ความสามารถหลัก (Key Features)

1. **การนำเข้ารูปภาพที่หลากหลาย (Multiple Input Modes)**
   - 📂 **ลากและวาง / อัปโหลดไฟล์ภาพ**: รองรับไฟล์ JPG, PNG, WEBP
   - 📷 **ถ่ายภาพผ่านกล้องโดยตรง**: รองรับทั้งกล้องหน้าและกล้องหลังของสมาร์ตโฟน หรือเว็บแคมคอมพิวเตอร์
   - 🍃 **ภาพตัวอย่างในตัวระบบ (Quick Samples)**: มีภาพตัวอย่างทั้งผักและทุเรียน (ผักกาดขาว, มะเขือเทศใบไหม้, พริกใบหงิก, แตงกวาราน้ำค้าง, คะน้ามีหนอน, **ทุเรียนไฟทอปธอร่ายางไหล**, **ใบทุเรียนสมบูรณ์**) ให้คลิกทดสอบได้ทันทีใน 1 คลิก

2. **ระบบการวินิจฉัยแบบ Dual-Engine (สองระบบประสานงาน)**
   - 🤖 **Google Gemini 2.5 Flash Vision AI**: วิเคราะห์ภาพด้วยโมเดลวิชันอัจฉริยะล่าสุด ครอบคลุมพืช ผักสวนครัว และไม้ผลเศรษฐกิจทุกชนิด โดยเฉพาะทุเรียน
   - 🌱 **Local Agricultural Expert Vision Engine (โหมดออฟไลน์)**: มีฐานข้อมูลโรคพืชและโรคทุเรียนโดยเฉพาะ สามารถทำงานได้สมบูรณ์แม้ออฟไลน์

3. **ข้อมูลผลการวิเคราะห์ที่ครบถ้วน (Comprehensive Diagnosis Report)**
   - 🏷️ **สถานะสุขภาพพืช**: ปกติ สมบูรณ์แข็งแรง (เขียว) / มีความผิดปกติปานกลาง (เหลือง) / โรครุนแรง (แดง)
   - 📊 **ระดับความมั่นใจ (Confidence Score)** และระดับความรุนแรงของโรค (Severity)
   - 🔍 **อาการที่ตรวจพบ (Symptoms)**: วิเคราะห์สีใบ รอยแผล วงไหม้ คราบรา หรือรอยกัดกิน
   - 🧬 **สาเหตุของการเกิดโรค (Causes)**: เชื้อรา แบคทีเรีย ไวรัส แมลงศัตรู หรือการขาดธาตุอาหาร
   - ⚡ **มาตรการเร่งด่วน (Immediate Actions)**: ขั้นตอนที่ต้องรีบทำทันทีเพื่อตัดวงจรการแพร่ระบาด
   - 🌿 **วิธีรักษาแบบอินทรีย์ / ชีวภัณฑ์ (Organic Solutions)**: การใช้เชื้อราไตรโคเดอร์มา แบคทีเรียบีที น้ำหมักสะเดา น้ำส้มควันไม้ สารละลายเบกกิ้งโซดา พร้อมอัตราส่วน
   - 🧪 **การรักษาด้วยสารควบคุมโรค (Chemical Treatments)**: สารเคมีที่ปลอดภัยพร้อมคำแนะนำระยะเว้นการเก็บเกี่ยว (PHI)
   - 🛡️ **การป้องกันระยะยาว (Prevention)**: การปรับปรุงดิน การให้น้ำ แสงแดด และการเว้นระยะปลูก
   - 🥗 **คำแนะนำด้านความปลอดภัยในการบริโภค (Edibility Note)**: ตรวจสอบว่ายังรับประทานได้หรือไม่ หรือต้องกำจัดทิ้ง

4. **เครื่องมืออำนวยความสะดวก**
   - 📱 **รองรับการติดตั้งบน Android (PWA & Native)**: สามารถสแกน QR Code เพื่อติดตั้งแอปบนหน้าจอมือถือ หรือเปิดโปรเจกต์เนทีฟใน `android/` ด้วย Android Studio เพื่อคอมไพล์เป็น APK
   - 🔊 **ระบบอ่านออกเสียงภาษาไทย (Thai Text-to-Speech)**: กดปุ่มเพื่อฟังเสียงสรุปผลการวินิจฉัยและวิธีรักษา
   - 🖨️ **พิมพ์ / บันทึกรายงาน PDF**: ออกรายงานผลตรวจสุขภาพพืชเป็นเอกสารได้ทันที
   - 📋 **คัดลอกข้อความสรุป**: คัดลอกผลการตรวจไปแชร์ใน LINE หรือส่งให้ผู้เชี่ยวชาญ
   - 📖 **คลังสารานุกรมโรคผักในตัว**: ค้นหาข้อมูลโรค อาการ และวิธีรักษาพืชชนิดต่างๆ ได้ตลอดเวลา

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### วิธีที่ 1: รันด้วย 1-Click บน Windows (ง่ายที่สุด)
- **เวอร์ชันเว็บแอปและ Android PWA (Flask)**: ดับเบิลคลิกที่ไฟล์ `run.bat`
- **เวอร์ชัน Streamlit App**: ดับเบิลคลิกที่ไฟล์ `run_streamlit.bat` (เปิดที่ http://localhost:8501)

---

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
- รันเวอร์ชัน Flask:
  ```powershell
  python app.py
  ```
- รันเวอร์ชัน Streamlit:
  ```powershell
  streamlit run streamlit_app.py
  ```

4. เปิดเว็บบราวเซอร์ไปที่:
   ```
   http://127.0.0.1:5000
   ```

## 🔑 การตั้งค่า Google Gemini API Key (อุปกรณ์เสริม)

ระบบถูกออกแบบมาให้ **ใช้งานได้ทันทีแม้ไม่ได้ใส่ API Key** โดยจะทำงานผ่านโหมด *Local Agricultural Expert Vision Engine* 

หากต้องการเปิดใช้งานพลังของ **Gemini 2.5 Flash Vision AI**:
1. สมัครรับ API Key ฟรีได้จาก [Google AI Studio](https://aistudio.google.com/)
2. ในหน้าเว็บแอปพลิเคชัน คลิกที่ไอคอนเฟือง **⚙️ (การตั้งค่า)** มุมขวาบน
3. กรอก API Key แล้วกด **บันทึกการตั้งค่า** (หรือตั้งค่าในไฟล์ `.env` ที่ `GEMINI_API_KEY=...`)

├── run.bat                    # สคริปต์คลิกเดียวสำหรับเปิดใช้งานบน Windows

    ├── css/

    ├── js/
